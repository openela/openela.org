### Understanding OpenELA

#### What is OpenELA?
OpenELA is a community-driven project that maintains an open Enterprise Linux source and the compatibility standard used by downstream distributions.

#### Why was OpenELA started?
Our founding organizations — CIQ, Oracle, and SUSE — believe deeply in the power of open source and collaboration. Recognizing that we can achieve more together than we can apart, we created OpenELA not just for ourselves, but to welcome others into a shared community. Together, we can collaboratively shape the future of Enterprise Linux.

#### Is OpenELA a distribution?
No. OpenELA provides source code and compatibility standards—not a packaged operating system.

#### How is OpenELA related to RHEL?
OpenELA maintains sources that are fully compatible with the widely adopted Enterprise Linux ABI, enabling downstream RHEL-compatible distributions.

### ELValidated and Compatibility 

#### What is ELValidated?
ELValidated is the open test suite that defines Enterprise Linux ABI compatibility. It ensures consistent runtime behavior across distributions.

#### Why does compatibility matter?
ISVs, IHVs, and enterprises depend on predictable, consistent behavior to reduce testing overhead and maintain stable deployments.

### Security, Licensing, and Trust

#### Is OpenELA legal?
Everything that OpenELA distributes is open source. All source code is maintained and published in compliance with open source licensing requirements, and is absolutely legal and appropriate to distribute.

#### How does OpenELA handle security updates?
Patches are maintained in public, and CVE workflows follow established open-source practices.

#### How can I get involved?
You can join working groups, contribute to source packages, help extend the ELValidated test suite, or become a member of OpenELA.

#### How are decisions made?
Through an open governance model that includes a Board, TSC, and community working groups.
